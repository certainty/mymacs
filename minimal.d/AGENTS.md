# Minimal config with bias towards builtins

This is a new profile for my emacs which is built from scratch.
It aims to make use of the most modern features of emacs 31.

IMPORTANT: when you use emacs-tools, set the EMACS environment variable to emacs31 and also make sure to set the
config root correctly. Figure out the currently installed emacs31 version on your own.

Important references:

- https://github.com/emacs-mirror/emacs/blob/master/etc/NEWS.31
- https://github.com/emacs-mirror/emacs/tree/emacs-31 (emacs 31 feature branch)
